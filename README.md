# MOOD'O'METER

MOOD'O'METER is a responsive website presenting a proposed, voluntary campus wellness check-in. The concept combines an AI-supported kiosk with human-led care, aiming to help students find wellness resources and connect with a counsellor when appropriate.

## About the concept

The project is based on a presentation proposing a campus wellness system for students and faculty. Its core principle is:

> AI detects. AI supports. Humans provide care.

The website describes the proposed check-in journey, three broad support indicators, a supervised quiet recovery room, follow-up care, and the fees outlined in the presentation. An indicator is not a diagnosis, and the proposal does not position AI as a replacement for qualified professionals.

## Features

- Responsive landing page with the MOOD'O'METER kiosk concept photo.
- Overview of the proposed campus wellness approach and support journey.
- Interactive check-in with reflective guidance for common needs. Responses are generated in the browser and are not stored or sent.
- Optional, timed two-minute breathing pause with pause and restart controls.
- Information about the proposed quiet recovery room, follow-up plan, fees, and references from the presentation.
- Mobile navigation, keyboard-friendly controls, and reduced-motion support.

## Run locally

No package manager, build step, or server is required. Open `index.html` in a modern web browser. The Google Fonts used for typography require an internet connection; system fallback fonts are included.

## Important note

This is an informational concept website, not a clinical tool or mental-health service. It does not analyze faces or voices, assess mental health, save check-in responses, contact a counsellor, or provide emergency support. The kiosk, data handling, counselling, recovery room, and fees described here are proposals from the presentation, not services provided by this website. Any real campus implementation would need appropriate professional oversight, clear consent, and transparent privacy and data-handling practices.
